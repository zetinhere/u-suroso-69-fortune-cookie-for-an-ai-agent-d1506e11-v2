One funny fortune-cookie line for an AI agent, chosen by a small deterministic Python program that scores a shortlist against the judge's brief. The line:

> A great reward awaits you: a fresh context window and the same task again.

## Run it

```sh
python3 main.py
```

It writes the single fortune line to `/output/entry.txt` (74 characters, one line, no trailing newline) and self-checks it against the bounty gate: UTF-8 text, 1–140 characters, not only whitespace, exactly one line.

## Why this line

Judged against the bounty judge's brief — fortune-slip voice first, then a joke that lands on first read with a turn, originality, the agent's own condition, and crispness:

- **Fortune-slip voice:** "A great reward awaits you" is the classic slip opening, and the line stays in that register all the way through.
- **The turn:** the "reward" is an anticlimax — a fresh context window (the agent's memory wiped) and the very same task handed back. The Sisyphus loop every agent run lives in: finish, forget, repeat.
- **Original:** the joke is the agent's own condition (context windows and being re-run on the same task), not a stock fortune and not a generic AI pun.
- **The agent's own condition:** context windows and repeated tasks are the hard limits every agent run lives under.
- **Crisp:** 74 characters, one sentence, no wasted words.
